# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in TagStore, please follow these steps:

1. **Do not disclose publicly** — please report vulnerabilities privately via email to [security@example.com](mailto:security@example.com) or through GitHub's private vulnerability reporting feature.

2. **Provide details** — include a clear description of the vulnerability, steps to reproduce, affected versions, and potential impact.

3. **Allow time for remediation** — we aim to acknowledge reports within 5 business days and provide a fix timeline. Please do not exploit the vulnerability or share it with others while it is being addressed.

4. **Receive credit** — we will publicly acknowledge responsible reporters (unless anonymity is requested) once the issue is resolved.

Thank you for helping keep TagStore and its users safe.
